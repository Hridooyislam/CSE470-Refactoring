## 📚 What's Included

### 🔄 1. Refactoring (7 Code Smells)
Practice refactoring a 150-line semester-fee program suffering from seven Fowler code smells:
1. **Inappropriate Naming** (*Mysterious Name*)
2. **Comments** (*Deodorant*)
3. **Long Method** (*Bloaters*)
4. **Long Parameter List** (*Bloaters*)
5. **Feature Envy** (*Couplers*)
6. **Duplicated Code** (*Dispensables*)
7. **Refused Bequest** (*Object-Orientation Abusers*)

*Includes step-by-step baby steps, regression test contracts, before/after diffs, and Python & Java solutions.*

### 📐 2. Design Patterns (15 Practice Problems + UML)
15 scenario problems with full problem statements, UML class diagrams, and reference solutions:
- **Observer Pattern** (Smart notice board, Online auction room, Alert hub, Flood warning)
- **Singleton Pattern** (Grade database, Print spooler, SMS gateway, Currency desk)
- **Adapter Pattern** (Payment vendors, Book search engines, Card reader)
- **Factory Method Pattern** (Courier branch, Result export portals, Upload service, IT helpdesk tickets)
- **Multi-Pattern Combinations** (Singleton + Observer, Adapter + Observer, Adapter + Factory Method, Singleton + Adapter, Singleton + Factory Method)
